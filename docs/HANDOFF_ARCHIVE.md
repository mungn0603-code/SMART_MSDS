## 2. API quota 계산 정정 (2026-08-04)
- 초기 계산: 200~400종 × 4섹션 = 800~1,600콜(1~2일 소요) — CAS로 섹션 직접
  조회 가능하다는 잘못된 가정에 근거
- 정정: 실제 KOSHA API는 CAS로 바로 섹션조회 불가 — 먼저 getChemList로
  chemId 조회가 선행되어야 함
- **확정 계산: 200종 × (chemId조회 1콜 + 섹션 4콜) = 정확히 1,000콜**
